Option 14 — Spatial field

Copy all files in this folder to the root of your GitHub Pages repository.
Then place the contents of html-head-snippet.txt inside your shared Jekyll
layout's <head>.

The browser favicons are circular with transparent corners. Apple/Android
icons use a full rounded-square treatment so device masking remains clean.

Included:
- favicon.svg
- favicon.ico (16/32/48)
- favicon-16x16.png
- favicon-32x32.png
- favicon-48x48.png
- favicon-96x96.png
- apple-touch-icon.png (180x180)
- android-chrome-192x192.png
- android-chrome-512x512.png
- maskable-icon-512x512.png
- mstile-150x150.png
- site.webmanifest
- browserconfig.xml
- html-head-snippet.txt
- preview.png
