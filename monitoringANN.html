Anna Malinovskaya, Pavlo Mozharovskyi, Philipp Otto (2024). Statistical process monitoring of artificial neural networks. Technometrics.

Summary

A deployed neural network may receive inputs from a different population before outcome labels arrive to reveal a change in prediction quality. Malinovskaya, Mozharovskyi and Otto (2024) monitor this possibility using the network's own embeddings, the vectors of activations produced by an internal layer. A nonparametric control chart compares the incoming embeddings with a reference sample from stable operation.

The paper compares data depth functions, benchmark outlier detectors and reference-sample construction. Its experiments cover convolutional image classification, LSTM-based question classification and feed-forward classification of sonar returns. The authors found asymmetric projection depth the most reliable option among the depth measures they examined, particularly when the embedding distribution was asymmetric.

Data depth and control charts

A data depth measures how central an embedding is relative to a reference cloud. For example, projection depth examines departures in multiple directions, so an embedding can receive low depth even if no individual coordinate is extreme. The authors turn these depths into ranks by comparing new and reference observations. A small rank provides a signal that the new embedding is unusual relative to the reference. This makes the monitoring statistic one-dimensional while preserving information about multivariate outlyingness.

The most useful layer, reference sample and depth depend on the network and data. The paper evaluates reference sets built from different subsets of the original data, including selections based on prediction confidence. A larger reference set did not consistently improve detection. Geometry mattered too. Simplicial depth can give the same zero depth to multiple points outside the reference convex hull, whereas projection depth can distinguish among them.

What the experiments and alarms show

The image experiment uses a ten-class classifier and assesses detection on held-out observations and observations supplied to represent a change. The question and sonar experiments extend the comparison to other input types and architectures. Across these experiments, the authors assess detection alongside false alarms in the stable test data. An apparent gain in sensitivity is less informative when the method also signals frequently on stable observations.

A chart alarm indicates a change in the representations it monitors. An investigation can then check acquisition conditions or changes in the input population and, once labels are available, measure prediction errors. Changes in the response given the inputs can leave the embedding distribution stable, so the chart addresses one observable aspect of model monitoring.
