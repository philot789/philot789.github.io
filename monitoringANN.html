What problem does this method address?

The method follows the representations that a trained network assigns to incoming observations. A control chart can flag a change relative to reference data before outcome labels arrive. An alarm warrants investigation because a shift in representations alone does not establish a loss of predictive accuracy.

When should this method be used?

Use this approach when a deployed network exposes an internal representation and comparable reference observations are available from a stable period. It is especially relevant when outcome labels arrive too late for routine monitoring.

Summary

Malinovskaya, Mozharovskyi and Otto (2024) apply statistical process monitoring to embeddings from a deployed artificial neural network. Data depth measures how central an embedding is relative to a reference sample. The method converts depth values to normalised ranks and monitors them sequentially with control charts.

Main contributions

  • Uses internal feature representations from a trained network to monitor incoming observations.
  • Combines multivariate data depth, normalised ranks and statistical process control.
  • Compares benchmark detectors across different network architectures and input formats.

Why monitor a deployed neural network?

Labels needed to measure prediction errors can arrive with a lag. Embeddings provide an earlier signal when the model’s representation of incoming inputs changes relative to its baseline.

How embedding-based control charts work

Select a layer, keep the trained network fixed, and collect reference embeddings from a stable period. Use a depth function to compare new embeddings with the reference distribution. A sequential control chart uses the ranks derived from these depth values to signal changes.

What does a monitoring alarm show?

An alarm indicates evidence of a shift in the monitored representation. Changes in the relationship between inputs and outcomes can occur without moving the embedding distribution. Evaluate prediction errors and subgroup performance when labels become available.

Applications of embedding-based monitoring

The paper compares approaches for several neural-network architectures and input formats. In deployment, changes in image acquisition, text sources or sensor conditions can motivate monitoring using an appropriate historical reference sample.

Choosing a reference period and responding to alarms

Choose a representative period under stable operation and calibrate the chart to its expected false-alarm behaviour. After an alarm, check data quality and changes in the mix of inputs. Use labels where available to assess changes in performance and decide whether updating the model is warranted.
