Open research tools for predicting spatial fields, modelling volatility and working with environmental monitoring data.

geossm · Python for spatiotemporal geostatistics

Use geossm for multivariate spatial prediction when monitoring sites differ between variables and measurements can be aligned to a regular time grid. Its low-rank SPDE state-space model can use the dependence between pollutants to interpolate at unobserved stations within the fitted period. The quick start fits a PM₁₀ model on bundled Agrimonia data and describes the supported Linux environment.

python -m pip install geossm

Cite the model: Rodeschini, J., Tedesco, L., Finazzi, F., Otto, P., & Fassò, A. (2026). Multivariate low-rank state–space model with SPDE approach for high-dimensional data. Spatial Statistics, 73, 100971. Record the installed package version alongside the citation.

spGARCH · R for spatial volatility

Use spGARCH when the magnitude of deviations clusters across nearby or connected locations. The package simulates spatial ARCH processes, estimates spatial ARCH models and spatial autoregressions with ARCH errors by quasi-maximum likelihood, and provides residual diagnostics. A first step is to open the documented simulation examples in R.

install.packages("spGARCH")
library(spGARCH)
help("sim.spARCH", package = "spGARCH")

Cite the software: Otto, P. (2019). spGARCH: An R-Package for Spatial and Spatiotemporal ARCH and GARCH models. The R Journal, 11(2), 401–420. The CRAN package DOI identifies the software record.

Agrimonia · Open air-quality data

Use Agrimonia to study daily air pollution alongside meteorology, emissions, and agricultural activity at 141 monitoring stations in and around Lombardy from 2016 to 2021. Start with a single pollutant and check its station coverage, original measurement resolution, and imputation uncertainty before fitting a model. The data descriptor explains how the sources were harmonised.

Cite the data: Record the DOI of the exact version downloaded from Zenodo. For the data descriptor, cite Fassò et al. (2023), Agrimonia: a dataset on livestock, meteorology and air quality in the Lombardy region, Italy, Scientific Data, 10, 143.
